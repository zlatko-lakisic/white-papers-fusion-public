# FUSION White Papers (Published Releases)

Published releases of the FUSION white paper.

**FUSION** (Federated Unified Sensor Intelligence on Network) is a concept for
carrier-deployed edge intelligence infrastructure: aggregating sensor inferences
and running AI/ML workloads across distributed network nodes, so that the
telecommunications network operates as an intelligence layer rather than
connectivity alone.
